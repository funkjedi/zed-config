# Architecture Decision Records

This directory records decisions made while developing the Unity Dark Zed theme: what was decided, why, and what it costs.

## Conventions

- One decision per file, named `NNNN-short-title.md` (e.g. `0001-keep-search-no-results-red.md`).
- Number sequentially; never reuse or renumber.
- Copy `template.md` to start a new record.
- Don't rewrite accepted records. If a decision changes, add a new record and mark the old one `Superseded by NNNN`.
